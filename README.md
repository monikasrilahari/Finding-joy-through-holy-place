# Finding Joy Through Holy Places

## Project Overview
Finding Joy Through Holy Places is a Flask and SQLite-based web application that showcases 20 famous holy places in India. It helps users explore spiritual destinations, search for places, save favourites, and plan their visits.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite

## Project Features

- Collection of 20 famous holy places in India
- Search and category filtering
- Place details and photographs
- Favourite places management
- Visit planning
- Admin dashboard

## Installation and Execution

1. Install Python.
2. Clone or download this repository.
3. Install the required packages:

```bash
pip install -r backend/requirements.txt
```

4. Run the Flask application from the project directory:

```bash
python backend/app.py
```

5. Open the local URL displayed in the terminal.

## Database
SQLite is used to store application data.

## Project Purpose
The main aim is to provide users with an easy way to discover holy places and organize their spiritual visits.
